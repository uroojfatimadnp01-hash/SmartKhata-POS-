# 📖 Smart Khata Ledger & Customer History System

A modern, responsive, and user-friendly web application designed for small shopkeepers and businesses to manage customer ledgers, daily transactions, and previous histories efficiently.

---

## Live Demo 
https://uroojfatimadnp01-hash.github.io/SmartKhata-POS-/

## 🚀 Features

* **Full Customer History Tracking:** Automatically loads and displays a customer's past purchases, total bills, and payment records when their name is entered.
* **Multi-Item Cart System:** Add multiple items with custom prices and quantities to a single day's transaction.
* **Payment-Only Support:** Allows customers to clear their previous balances or pay dues even without purchasing new items.
* **Live Calculations:** Automatically calculates previous balances, current cart totals, total payable amounts, and remaining balances in real-time.
* **Reset / Clear Khata:** Option to reset or clear a customer's history once their ledger balance is fully settled.
* **Print & PDF Export:** Integrated receipt preview with print/save functionality.
* **Persistent Storage:** Uses browser `localStorage` to save data safely across browser sessions.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and layout.
* **CSS3:** Modern styling, flexbox, and print media queries.
* **JavaScript (ES6):** Dynamic DOM manipulation, array methods, and data handling logic.
